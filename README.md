# Student Attendance Management System

## Introduction
The Student Attendance Management System is a web-based application
used to manage student attendance.

## Features
- Student registration
- Mark attendance
- View attendance
- Generate attendance reports

## Technologies Used
- HTML
- CSS
- JavaScript

## Installation
1. Download or clone the project from GitHub.
2. Open the project folder in VS Code.
3. Make sure all required files are present.
4. Open `index.html` in a web browser.

## Usage

1. Open the Student Attendance Management System.
2. Enter the student's name.
3. Click **Add Student**.
4. Click **Present** or **Absent** to mark attendance.
5. View the attendance summary.
